Key Kotlin Concepts

data class (= TypeScript interface + auto-methods)

@Serializable
data class Worker(
    val id: Int,
    val name: String,
    val email: String,
    val phone: String,
    val emailVerified: Boolean = false,  // default value
    val stats: WorkerStats = WorkerStats(),
    val createdAt: Instant,
    val updatedAt: Instant
)
// Automatically generates: equals(), hashCode(), toString(), copy()

sealed class (= TypeScript discriminated union)

sealed class ApiResult<out T> {
    data class Success<T>(val data: T) : ApiResult<T>()
    data class Error(val message: String) : ApiResult<Nothing>()
}

// Compiler enforces exhaustive handling:
when (result) {
    is ApiResult.Success -> showData(result.data)
    is ApiResult.Error -> showError(result.message)
    // No "else" needed — compiler knows all cases
}

suspend fun (= async function)

// TypeScript:
async function getWorker(id: number): Promise<Worker> {
    const response = await fetch(`/api/workers/${id}`);
    return response.json();
}

// Kotlin:
suspend fun getWorker(id: Int): Worker {
    return httpClient.get("/api/workers/$id").body()
    // No "await" keyword — suspend functions auto-pause
}

object (= singleton / static module)

object GeofenceVerification {
    fun isWithinGeofence(user: Point, checkpoint: Point, radius: Double): Boolean {
        return distanceMeters(user, checkpoint) <= radius
    }
}
// Usage: GeofenceVerification.isWithinGeofence(...)
// Like a TS module with exported functions — no instantiation needed

Routes Layer

HTTP endpoint definitions. Parses request params, calls services, returns JSON.

fun Routing.workerRoutes() {
    route("/api/workers") {
        get {
            val workers = workerService.getAll()
            call.respond(workers)
        }
    }
}

Services Layer

Business logic + database queries. Converts DB rows to shared models.

class WorkerService {
    suspend fun getAll() = dbQuery {
        Workers.selectAll()
            .map { it.toWorker() }
    }
}

Important: Shared Database

Both gcc-site (Next.js) and gcc-kmp (Ktor) connect to the same Neon PostgreSQL database. The Ktor server does NOT create or modify tables — it reads the existing schema that gcc-site's Drizzle ORM created. If column names don't match, update the Tables.kt string values.

Dependency Injection (Koin)

How services are created and shared across the app.

What is Dependency Injection?

Instead of creating services inside routes (tight coupling), we declare what services exist in one place and let the framework "inject" them where needed. This makes testing easy (swap real DB with mock) and keeps code modular.

graph LR Module[Koin Module
declares all services] -->|injects| Route1[WorkerRoutes] Module -->|injects| Route2[RouteRoutes] Module -->|injects| Route3[BlockRoutes] Module -->|creates| WS[WorkerService] Module -->|creates| RS[RouteService] Module -->|creates| BS[BlockService] Module -->|creates| SS[StatsService] SS -->|depends on| WS SS -->|depends on| BS style Module fill:#22C55E,color:#000

TypeScript vs Kotlin DI

// TypeScript: Manual dependency creation
const workerService = new WorkerService(db);
const statsService = new StatsService(workerService);
// Must wire everything manually, order matters

// Kotlin with Koin: Declarative
val appModule = module {
    single { WorkerService() }                           // create once, reuse
    single { StatsService(get(), get(), get(), get()) }  // get() = auto-resolve
}
// Koin resolves the dependency graph automatically

The "Contract" Pattern

These shared models are the single source of truth for data shape. The server serializes database rows into these models. The mobile app deserializes API responses into the exact same models. If a field is added/removed, the compiler catches every affected location across server, Android, and iOS.

Geofence Logic

Shared Haversine distance calculation for checkpoint verification.

How Geofencing Works

flowchart TB GPS[Worker GPS Position] --> CALC[Haversine Distance] CP[Checkpoint Coordinates] --> CALC CALC --> CHECK{Distance <= 15m?} CHECK -->|Yes| INSIDE[Within Geofence
Can take photo] CHECK -->|No| OUTSIDE[Outside Geofence
Must move closer] style INSIDE fill:#22C55E,color:#000 style OUTSIDE fill:#EF4444,color:#fff

The Haversine formula calculates the great-circle distance between two points on a sphere (Earth). It accounts for Earth's curvature, making it accurate for the short distances (0-50m) used in checkpoint verification. The same GeofenceVerification object runs on both the phone (for real-time UI) and the server (for authoritative validation).

Navigation (Decompose)

Type-safe navigation with lifecycle awareness. Coming in Step 3.

Decompose provides navigation that works identically on Android and iOS. Unlike React Navigation (which wraps native navigators), Decompose manages the navigation stack in shared Kotlin code. Each screen gets its own component with lifecycle callbacks.
