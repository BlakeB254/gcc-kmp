The processing cycle

1Raw ingestPresigned uploads to zero-egress object storage. raw/… is append-only — never modified, never deleted
→
2Index + queue30-min sweeps mirror every session to the DB and enqueue durable, lease-locked reconstruction jobs
→
3GPU reconstructionOn-prem NVIDIA DGX fuses posed RGBD, registers sessions via GPS-seeded ICP, produces splats + meshes
→
4Versioned publishreconstructed/{cell}/{v}/ point cloud · splat · web splat, with full session provenance in Postgres
→
5ServingSigned-URL delivery; the 3D viewer anchors assets at true GPS (ECEF) over photoreal base tiles
ElementDesign choice
Capture formatRotating chunks: HEVC video + LiDAR depth keyframes (LZFSE) + per-frame pose/intrinsics sidecar — 30 posed frames/sec, thermal-aware.
Durable queuePostgres row-locking (FOR UPDATE SKIP LOCKED), 30-min leases, 3 recorded attempts; job = session, work unit = the whole cell.
Web deliveryCompressed splats (.spz ≈ 5× smaller) for apps; full-fidelity archives retained for reprocessing.

The geographic scan cache — a health record per location

Every point on the ground maps deterministically to a ~3–10 m grid cell ID — one shared formula across the phone, servers, and storage paths. Each cell accumulates:

  • Coverage tier — seen → grazed → close (quality-gated). Tiers only upgrade; the append-only event log is the source of truth.
  • Freshness — first/last scan timestamps drive “needs rescan” priority and the fog-of-war map.
  • Observation lifecycle — findings display until the cell is rescanned, then auto-resolve to still-present or cleaned.
  • 3D status — which reconstruction version covers the cell; canonical only after multi-session agreement.
the cell health grid:
■ close · ■ grazed · ■ finding · ■ cleaned

Trust & integrity choices

  • Provenance-first — every derived asset links to its exact source sessions.
  • Append-only everything — raw scans, coverage events, and versions never overwrite history.
  • Evidence validation — visual evidence must be geographically consistent (≤150 m) with the report it documents.
  • Cross-session agreement — a cell's model is canonical only once ≥3 independent scans register consistently.
