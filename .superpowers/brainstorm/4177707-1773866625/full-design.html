SCOUTING
AR camera active. Fog-of-war clearing. AI detecting trash. Coverage % increasing. User walks route freely from any start point.
SCOUT_REVIEW
Coverage threshold met + loop closed. Shows summary: X hotspots found, estimated cleanup time. User confirms to start cleaning.
CLEANING
Minimap with hotspot pins. Free roam + proximity alerts. Camera confirmation at each spot. Timer running.

2. Scout Lap — AR Camera + Minimap

Primary view during scouting phase

AR Camera (full screen)
Live camera with fog-of-war overlay. Dark areas = unscanned. Clear areas = scanned. Fog clears based on camera frustum intersection with route corridor.
Trash Markers (AR anchored)
Spatially anchored to real-world position. Show type + severity + estimated volume. Pulse animation for new detections. Persist as you look away and back.
AI Direction Banner
Natural language guidance: "Pan left", "Look behind you", "Walk toward the dumpster". Updates every 3-5 seconds based on unscanned areas nearest to user.
Minimap (top-right)
Overhead view of route. Green = scanned, dark = unscanned. Blue dot = user. Red dots = detected hotspots. Tappable to expand to full map.
Coverage Bar
Progress toward coverage threshold. Must hit 85%+ AND return to start position to complete scout lap.
Hotspot Counter
Running count of detected trash areas. Tappable to see list with thumbnails.

3. Clean Lap — Minimap + Proximity Alerts

After scouting, the user cleans with guided hotspot navigation

Plastic bags + bottles · Sev 3 · ~2 gal
CLEAN

Full Map View
Route overlay with all hotspots visible. Green checkmark = cleaned. Red pulsing = nearby (proximity alert). Yellow = pending. User's blue dot shows position.
Proximity Alert Card
Appears when within ~20m of a hotspot. Shows scout photo thumbnail, trash type/severity, distance. "CLEAN" button opens camera for confirmation.
Confirmation Flow
AR devices: Re-scan area, AI compares 3D scene before/after.
GPS devices: Take after photo, AI compares images + geofence check.
Progress Segments
Top bar shows X/Y hotspots cleaned. No required order — user can approach hotspots in any sequence.
Completion
All hotspots confirmed → submit session. Total time, trash volume, before/after evidence all bundled into RouteScan entity.
