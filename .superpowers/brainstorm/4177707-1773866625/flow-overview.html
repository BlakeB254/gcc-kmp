Scout & Clean: Two-Lap Flow

The complete user journey — AR devices get spatial scanning, GPS devices get manual tagging

Phase Overview

1

Scout Lap

Start at route beginning
GPS confirms position at first checkpoint
Walk route with camera active
AR: Fog-of-war clears as camera scans area
GPS: Manual photo capture at dirty spots
AI detects & tags trash
AR: Real-time object detection, spatial anchors placed
GPS: On-device analysis of captured photos
AI guides coverage
"Look left toward the alley" / "Turn around, missed area behind you"
Return to start
Coverage % shown. Must hit threshold to proceed.
2

Clean Lap

Minimap shows trash hotspots
Interest areas from scout lap displayed as markers
Navigate to each hotspot
Route optimized for efficient cleanup order
Clean the area
Timer running, user picks up trash at each spot
Confirm cleanup with camera
AR: Re-scan area, AI compares before/after
GPS: Take "after" photo, AI similarity check
Complete & submit
All hotspots confirmed clean. Points + evidence submitted.

Key Question: How should the Clean Lap handle hotspot navigation?

When the user finishes scouting and starts cleaning, how do they move between identified trash areas?

A

Free Roam + Proximity Alerts

User walks freely. When near a hotspot, phone buzzes and shows the before-photo + "Clean this area" prompt. Hotspots glow on minimap. No forced order.

B

Optimized Route with Waypoints

AI calculates most efficient path through all hotspots. User follows guided route (like Google Maps directions) from hotspot to hotspot. Structured but less flexible.

C

Hybrid: Suggested Order + Free Skip

AI suggests optimal order and highlights "next" hotspot, but user can tap any hotspot on the minimap to navigate there instead. Best of both worlds.
