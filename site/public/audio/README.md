# Audio Assets for GCC Remotion Ad

## Required Audio Files

Download these royalty-free audio files and place them in this folder:

### 1. Main Beat (`beat.mp3`)
- **Source**: [Pixabay Drill Music](https://pixabay.com/music/search/drill/)
- **Recommended**: Search for "hard drill beat" or "trap instrumental"
- **BPM**: 130-150 (ideal for viral content)
- **Duration**: 60+ seconds
- **License**: CC0 (Pixabay Content License)
