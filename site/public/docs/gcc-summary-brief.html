How It Works

The Block Cleaning 2-Lap Model

1

Documentation Lap

Worker walks the block with GPS tracking, photographing every dirty spot. AI classifies waste into 12 categories, estimates volume and weight, and scores severity 1–5. LiDAR variant uses depth scanning for precise volumetric measurements.

2

Cleanup Lap

Worker returns with supplies, cleans each documented spot, takes after photos. System creates GPS-verified before/after pairs. Two variants: AR (LiDAR + smart glasses, hands-free) and Photo (camera-only, lower barrier to entry).

Data & Technology

AI Analysis Pipeline

On-Device AI

CoreML (iOS) and TFLite (Android). No cloud dependency for classification.

12 Waste Categories

Automatic classification with severity scoring (1–5 scale).

Volume & Weight Estimation

LiDAR depth analysis on iPhone Pro for precise volumetric measurements.

Security & Anti-Fraud

Device Attestation

Device model, OS, and live-capture flag verified per submission.

GPS Lock & Dedup

200m proximity enforcement. 50m duplicate radius buffer. Session binding.

SOC2-Aligned Controls

Encryption at rest and in transit. RBAC. Full audit logging. Live capture required.

Open Data Export

SODA-Compatible API

Chicago Data Portal format. Standard REST endpoints for bulk and filtered queries.

25+ Fields Per Record

GPS, photos, AI classification, severity, volume, weight, status, timestamps, before/after pairs.

Civic Integration

Community area, ward, police district, and census tract linkage for every data point.
