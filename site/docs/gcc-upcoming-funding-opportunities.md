## Priority Application Concepts

### EPA EJ / Schwemm / CHEJ

Project name: North Lawndale Block Environmental Health and Resident Stewardship Pilot

Core ask: fund cleanup supplies, safety equipment, resident outreach, training, verification, data reporting, and environmental-health documentation for a concentrated North Lawndale pilot.

### NFWF Five Star / Illinois EPA 319 / SCALE

Project name: North Lawndale Watershed Stewardship and Clean Blocks Partnership

Core ask: connect GCC's block cleanup model to storm-drain-adjacent litter prevention, public-space restoration, youth education, water-quality outreach, and recurring cleanup metrics. Add partner letters from a community organization, environmental/watershed partner, public land/site partner, school/youth partner, and civic sponsor.

### Polk Bros.

Project name: Youth Block Stewardship and Civic Power Lab

Core ask: pay and train youth up to age 26 to identify environmental disorder, clean/verify blocks, gather resident input, and present block-level priorities to sponsors, funders, and civic stakeholders.

### CCT Sponsorships

Event name: North Lawndale Block Report Convening

Core ask: sponsor a public convening where GCC shares before/after block data, resident worker stories, UIC sponsorship proof, and a next-block funding map.

### AmeriCorps NCCC / VISTA

Project name: GCC Cleanup Corps Capacity Project

Core ask: use service members for outreach, mapping, volunteer coordination, data cleanup, event logistics, and resident support so GCC staff can focus on paid worker onboarding and funder relationships.
