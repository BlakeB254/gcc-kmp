# GCC Sponsor Calculator - Upsell Image Specifications

This document provides detailed visual specifications for each upsell category in the sponsor calculator. These descriptions can be used to:
- Generate images via AI (Gemini, FLUX, Midjourney, etc.)
- Brief photographers/videographers for real content
- Serve as comprehensive alt text for accessibility
- Guide designers for custom illustrations

## Brand Guidelines

**Color Palette:**
- Primary Gold: `#D4AF37` (worker vests, branding elements)
- Secondary Brown: `#5D4037` (earth tones, professional feel)
- Accent Green: `#4CAF50` (environmental services)
- Accent Sky: `#2196F3` (digital/media elements)

**Visual Style:**
- Documentary/photojournalistic feel
- Authentic Chicago urban settings (brick buildings, wide sidewalks)
- Diverse representation (African American majority, reflecting North Lawndale)
- Professional but approachable
- Emphasis on community pride and transformation

## Technical Requirements

**Static Images:**
- Format: PNG (transparency support) or WebP (smaller files)
- Resolution: 1920x1080 minimum (16:9)
- Fallback: Current SVG placeholders work well
- Alt text: Use descriptions above

**Video Content:**
- Format: MP4 (H.264)
- Resolution: 1080p minimum
- Duration: 20-40 seconds per category
- Autoplay: Muted, with play controls
- Fallback: Static image poster frame

---

## Notes for Photographers/Videographers

If producing real content (not AI-generated):

1. **Location:** North Lawndale, Chicago (authenticity matters)
2. **Talent:** Hire actual community members as models
3. **Wardrobe:** GCC will provide branded gold vests
4. **Timing:** Golden hour preferred (early AM or late PM)
5. **Releases:** Get signed photo/video releases
6. **Style:** Documentary, not overly staged
7. **Diversity:** Reflect the actual community demographics
